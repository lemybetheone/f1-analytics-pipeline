# Attribution — data in this directory

Every file in `discovery/findings/` contains data, or measurements derived from
data, obtained from the **[Jolpica-F1 API](https://github.com/jolpica/jolpica-f1)**.

That data is licensed under
**[CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/)**
(Creative Commons Attribution-NonCommercial-ShareAlike 4.0 International).

Because ShareAlike reaches adaptations of the data, the *contents* of these
files are redistributed under the same licence. The scripts in `discovery/`
that produced them are code, not adaptations of the data, and are covered by
the repository's own code licence.

Held here as Phase 0 evidence — the schema decisions in
[`context/SCHEMA.md`](../../context/SCHEMA.md) cite these measurements, so the
files exist to make those decisions checkable. They are excerpts and aggregate
statistics, not a bulk redistribution of the dataset.
